# DJ TOTO

Cabina DJ infantil 3D construida con Vite + React + TypeScript.

## Funciones
- 2 decks independientes
- Carga de audio local desde el dispositivo
- Play / pausa
- Volumen por deck
- Pitch / velocidad
- Crossfader
- Pads de sonidos generados con Web Audio API
- Efectos visuales: Flash, Neon, Space y Confetti
- Interfaz 3D con perspectiva CSS
- Responsive para escritorio y tablet
- Sin backend

## Ejecutar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

El resultado se genera en `dist/`.
